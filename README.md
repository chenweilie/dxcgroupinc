## Overview

DXC Group Inc develops frontier agent orchestration systems designed to bridge multimodal cognitive reasoning with real-world enterprise action. By leveraging Claude 5.5 Sonnet's 200,000-token context window, advanced visual reasoning, and native tool execution, OmniFlow enables deterministic automation across legacy desktop UIs, ERP databases, and distributed infrastructure.

## Key Capabilities

1. **Multimodal Document & Inspection Intelligence**:
   - Visual parsing of CAD diagrams, bills of lading, complex invoices, and clinical documents.
   - 99.4% cross-reference fidelity with enterprise SAP, Oracle, and Salesforce databases.

2. **Native Computer Use Automation**:
   - Direct interaction with legacy desktop systems without custom API wrappers.
   - Autonomous UI navigation, keyboard entry, and visual assertion verification.

3. **Model Context Protocol (MCP) Standard**:
   - Standardized, zero-trust tool access connecting Claude to ClickHouse, PostgreSQL, GitHub, and corporate microservices.

4. **Deterministic Guardrails & Auditability**:
   - Multi-stage validation checkpoints.
   - Automatic Human-in-the-Loop (HITL) escalation for irreversible operations.
   - Cryptographic action logging for complete regulatory compliance.

## Enterprise Security & Privacy

- **Zero Data Retention**: Under Anthropic commercial terms, customer operational data and prompts are never retained or used for foundational model training.
- **End-to-End Encryption**: TLS 1.3 in transit, AES-256 at rest in dedicated enterprise cloud VPC enclaves.
- **Compliance Roadmap**: Designed to meet SOC 2 Type II, HIPAA, and GDPR standards.
