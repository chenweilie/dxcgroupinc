Privacy Policy

Last updated: October 2026

1. Overview

DXC Group Inc ("we," "our," or "us") provides enterprise autonomous agent infrastructure and workflow automation solutions. We take the privacy and confidentiality of our clients and partners seriously.

2. Zero Model Training Guarantee

In accordance with Anthropic’s Commercial Terms of Service, all customer operational data, document inputs, screen recordings, and prompts processed via our integration with the Anthropic Claude API are never used to train, retrain, or improve foundational AI models.

3. Information We Collect

  • Contact information (such as your name, corporate email address, and phone number).
  • Enterprise workflow configuration parameters and tool schemas.

4. Data Security & Storage

All data in transit is encrypted using modern TLS 1.3 encryption. Data at rest is encrypted using AES-256 standards within dedicated enterprise cloud VPC environments.
