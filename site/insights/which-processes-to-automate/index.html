Which processes are worth automating? A five-question screen

A simple screen for deciding whether a process is a good candidate for AI-assisted automation.

DXC Group Inc. · 2026-10-30

Not every slow process should be automated. Some are slow because the underlying decision is hard, or because the process itself is broken. Five questions help separate good candidates from poor ones.

1. How often does it happen?

Volume pays for the work of building and maintaining automation. A task done twice a month rarely justifies it. A task done every hour usually does.

2. Can you write down what “correct” looks like?

If two experienced people would disagree about the right answer, a rule or a model will not settle it. Start with work where correctness is clear: an amount matches or it does not, a field is present or it is not.

3. How varied are the inputs?

Fixed-format inputs can be handled with plain rules. Varied inputs, such as invoices from many suppliers or free-text emails, are where language models add real value.

4. What does a mistake cost?

A wrong category on a support ticket is cheap to fix. A wrong payment is not. The higher the cost, the more review you need, and the less it makes sense to remove the person entirely.

5. Can a reviewer catch errors?

Good candidates let a person scan exceptions quickly. If checking the result takes as long as doing the work, automation will not save time.

What to do with the answers

Processes that score well on all five are good pilots. Processes that fail the second question usually need clearer rules before any technology. Measure the current process first, so you can tell whether the change actually helped.
