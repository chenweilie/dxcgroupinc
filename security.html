Security Whitepaper & Governance

DXC Group Inc Enterprise Security Architecture v2.4

1. Frontier LLM Isolation & Anthropic Commercial Terms

DXC Group's OmniFlow platform connects directly to Anthropic's enterprise endpoints under commercial terms that strictly enforce zero data retention. Your confidential data, financial figures, schemas, and user interfaces are never stored for foundation model training.

2. Model Context Protocol (MCP) Access Controls

Tool calls to production databases (PostgreSQL, ClickHouse, Snowflake) and enterprise software (Salesforce, SAP, Workday) operate via fine-grained MCP role-based permissions. Every execution step is verified against pre-defined capability scopes before issuance.

3. Deterministic Guardrails & Human-in-the-Loop

Autonomous agents operate within strict confidence boundaries. When an action has irreversible consequences (e.g. monetary transfers or database mutations), OmniFlow automatically triggers a Human-in-the-Loop verification checkpoint with full context justification.

4. Cryptographic Audit Trail

Every decision step, visual screenshot delta, and tool response is hashed into an immutable audit trail, providing complete compliance defensibility for regulatory reviews and internal audits.
